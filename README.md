# ts-dnd-utils

Headless drag & drop primitives for React — typed payloads, drag groups, and no
runtime dependencies.

Built on the browser's native HTML5 drag & drop events. The library owns the
awkward parts — the drag payload, group matching while `dataTransfer` is in
protected mode, and the handle-gating that keeps text inside a draggable row
selectable — and takes no position at all on how any of it looks.

> **Status: under construction.** The package is not published yet.
